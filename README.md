# Diario di Viaggio

Web app installabile su iPhone per tenere un diario di viaggio giorno per giorno: luoghi visitati, cibo, hotel, autista, meteo e vestiti, spese e foto.

## Installazione su iPhone

1. Apri l'indirizzo dell'app in **Safari**.
2. Tocca **Condividi** → **Aggiungi alla schermata Home**.
3. Apri l'app dall'icona "Diario".

## Dove sono i dati

Diario e foto restano **solo sul telefono** (non in questo repository). Dalla scheda **Viaggio** usa **Salva backup** ogni due o tre giorni e conserva il file in File o iCloud Drive.

## Aggiornamenti

Le modifiche pubblicate in questo repository arrivano da sole: quando l'app è online scarica l'ultima versione all'apertura. Puoi anche toccare **Cerca aggiornamenti** nella scheda Viaggio.

## File

- `index.html` – l'app
- `sw.js` – funzionamento offline e aggiornamenti
- `manifest.webmanifest`, `icons/` – nome e icona sulla schermata Home
